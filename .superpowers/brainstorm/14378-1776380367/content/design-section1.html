Minden kalkulátor tartalmaz

  • Input mezők validációval (nem-numerikus input nem jelenik meg)
  • Azonnali eredmény (nincs submit gomb)
  • Eredmény táblázat / amortizációs táblázat ahol releváns
  • Shareable URL (?value= query param)
  • AdSense slot (header + result alatt)
  • Egyedi H1, title, meta description, JSON-LD
